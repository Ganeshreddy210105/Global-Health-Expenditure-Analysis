# 🌍 Global Health Expenditure Analysis (Power BI)

This project provides an interactive **Power BI dashboard analysis** on **Global Health Expenditure** across different countries and years.  
The goal is to understand how health spending varies globally and identify trends in expenditure patterns.

---

## 📌 Project Overview
Health expenditure plays a major role in a country's development and public well-being.  
This dashboard helps in analyzing:

- Total health expenditure across countries
- Government vs Private health spending
- Expenditure trends over time
- Country-wise comparison and insights

---

## 📊 Dashboards Included

### ✅ Page 1: Global Overview Dashboard
- Total Health Expenditure (Overall)
- Country-wise spending comparison
- Year-wise spending trend

### ✅ Page 2: Government vs Private Spending Dashboard
- Government health expenditure
- Private health expenditure
- Comparison using charts and KPIs

### ✅ Page 3: Trend & Insights Dashboard
- Expenditure changes over time
- Top spending countries
- Insights for decision making
